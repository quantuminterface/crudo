Welcome to crudo's documentation!
==================================

.. toctree::
   :maxdepth: 2
   :caption: Contents:

CRUDO (Control and Readout Utilities for low-temperature Detector Operation) is an abstraction layer built on top of cirque.
It offers higher-level functionality to conveniently configure the QiController readout systems used for experiments with
frequency-division multiplexed low-temperature detectors.
